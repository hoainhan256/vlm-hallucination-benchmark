# Qwen3-VL MMHal-Bench Deliverable Package

Nhiệm vụ: Chạy mô hình Qwen3-VL-4B-Instruct trên dataset MMHal-Bench.

## Danh sách tệp:
- `qwen3_mmhal_responses.json`: Kết quả suy luận của 96 mẫu MMHal-Bench.
- `inference_config.json`: Cấu hình thực nghiệm chi tiết.
- `inference_summary.json`: Báo cáo thống kê số mẫu thành công/thất bại.
- `inference_log.txt`: Nhật ký tiến trình suy luận.
- `qwen3_vl.py`: Model adapter cho Qwen3-VL.
- `run_qwen3_mmhal.py`: Script thực thi suy luận.
